# Zetas Barber

Página web de **Zetas Barber**, barbería en El Zorzal, General Pacheco, Tigre (Buenos Aires).

- Reserva de turnos online que se guardan en Google Sheets (vía Google Apps Script).
- Calculadora de corte a domicilio por distancia real en auto (OpenStreetMap: Photon, Nominatim y OSRM).
- Precios, horarios y datos de contacto editables en [`js/config.js`](js/config.js).

Guía paso a paso para conectar la planilla y publicar la página: [INSTRUCCIONES.md](INSTRUCCIONES.md).
